Tags Básicas

<h1> ao <h6>: Definem a hierarquia de títulos da página, onde <h1> é o título principal e <h6> o subtítulo de menor importância.

<p>: Define um parágrafo de texto.

<ul>, <ol> e <li>: Criam listas não ordenadas (com marcadores), listas ordenadas (numeradas) e os itens dentro de cada lista.

<hr>: Insere uma linha horizontal para separar seções temáticas.

Links e Imagens

<a href="...">: Tag âncora usada para criar hiperlinks entre páginas do site, seções internas (usando #) ou endereços externos.

<img src="..." alt="...">: Insere uma imagem na página, onde src indica o caminho do arquivo e alt fornece a descrição alternativa.

Caminhos Relativos vs. Absolutos: Caminhos relativos navegam pelas pastas do próprio projeto (ex: ../index.html), enquanto caminhos absolutos usam a URL completa (ex: https://...).
